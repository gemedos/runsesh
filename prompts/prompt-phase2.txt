FACTS YOU MUST DESIGN AROUND (verify against the current official docs before relying on any of them, and tell me if something differs)
- Health Connect needs Android 9 or higher with Google Play services. On Android 14 and higher it is built into the system and can count steps on the phone by itself once any app has been granted the steps read permission. On Android 13 and lower the user must install the Health Connect app from the Play Store, and steps only exist if some other app writes them into Health Connect.
- On Android 14+, native phone steps only start accumulating after my app is granted the steps permission. Tell users that steps count from the moment they connect.
- Since the June 2026 update, steps counted natively by Health Connect are attributed to a synthetic package name. Therefore NEVER filter steps by data origin or package name, and NEVER sum raw records. Use the platform's aggregation (daily SUM) so overlapping phone and watch data is de-duplicated.
- Reading in the foreground needs no extra permission. Background reading needs a separate permission, which we do not want.
- Without the history permission Health Connect only returns data from 30 days before the first grant. That is enough for daily totals.
- The official @capacitor/health-fitness plugin returns results as JSON-encoded strings; parse and validate them. It does not offer elevation or floors for Android, so the "elevation bonus" party rule is NOT supported in this part (keep the setting in the UI as "coming later"). It has no background sync to a server, so sync happens when the app opens or resumes.
- If its configuration file is missing, the plugin declares every Health Connect permission. We must therefore create the config file and verify the final merged manifest. The plugin requires a public https privacy policy URL, and permission requests fail without one.
- If the user denies the permission twice, Android locks the app out of asking again. Explain how to reset it during testing (Health Connect app, App permissions, allow all then remove all).
- I have NOT verified that a sideloaded app (not installed from Google Play) can use Health Connect. The proof in step 2 must settle this before you build anything else.
